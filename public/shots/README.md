# Project screenshots

Drop screenshots here, then add `shot: "<filename>"` to the matching entry in
the `deployments` array in `app/page.tsx`. Omit the field and the card renders
text-only — nothing breaks.

## Requirements

- **Aspect ratio:** 16:10. The card crops to this from the top, so put the most
  recognizable part of the UI in the upper portion.
- **Size:** 1600×1000 px is ideal. Anything above ~1200px wide is fine; Next
  optimizes and resizes at request time.
- **Format:** `.png` for UI (crisp text), `.jpg` only for photo-heavy shots.
- **Naming:** match the repo, e.g. `nekostream.png`, `rss2mail.png`.

## What makes a good one

Capture the app doing its actual job with real content — a populated list, a
running visualizer, a filled dashboard. Empty states and login screens tell a
recruiter nothing. Hide personal data, real email addresses, and API tokens
before capturing.
